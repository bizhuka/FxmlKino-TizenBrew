# FxmlKino for TizenBrew

[Русская версия](README.ru.md)

**FxmlKino** shows two movie sites, [HDRezka](https://kz.rezka.biz/) and [Kinogo](https://sim.kinogo.tm/),
on Samsung Smart TVs as [Fork browser](https://wiki.forkbrowser.top/wiki/FXML) (FXML) pages.

- No ads and no account needed.
- Pick the season, episode and voice-over, and the quality up to 1080p, as on the site.
- The sites are read **by the TV itself**: no PC and no server. If the sites open on your
  computer, they should work on your TV too.

This repository is FxmlKino as a **[TizenBrew](https://github.com/reisxd/TizenBrew) module**. With
TizenBrew there's no signing and no device IDs: it works on any Samsung TV TizenBrew supports
(2017 and newer).

## Installing

1. **Install TizenBrew** on the TV once, with the
   [TizenBrew Installer](https://github.com/reisxd/TizenBrewInstaller/releases/latest). Follow
   [TizenBrew's guide](https://github.com/reisxd/TizenBrew/blob/main/docs/README.md).
2. **Open TizenBrew** on the TV and press the **green** button for the module manager.
3. Choose **Add GitHub Module** and type:
   ```
   bizhuka/FxmlKino-TizenBrew
   ```
4. Back on the TizenBrew home screen, open **FxmlKino**.

TizenBrew starts FxmlKino's parser in the background when you open it. To open FxmlKino right
when TizenBrew starts, set it under TizenBrew's **Settings → Autolaunch**.

## Without TizenBrew

A standalone app with its own Windows installer is in
[FxmlKino-TV](https://github.com/bizhuka/FxmlKino-TV).

## Files

| File | Purpose |
|---|---|
| `package.json` | Module description for TizenBrew: app page, parser service, remote keys. |
| `index.html`, `js/`, `static/`, `icon.png` | The app: the Fork browser launcher. |
| `service/index.js` | The parser, which TizenBrew runs on the TV (serves `http://127.0.0.1:8787/`). |

This repository is generated by the author's build tool. The parser's source isn't published here.
